## Overview

TAL-BassLine-101 emulates the Roland SH-101 monophonic synthesizer with its distinctive subtractive architecture, including VCO, VCF, VCA, and the 100-step sequencer from the original instrument.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **TAL-BassLine-101** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **SH-101 Model** | Accurate VCO, VCF, and VCA circuit emulation matching hardware tone |
| **100-Step Sequencer** | On-board step sequencer matching the original SH-101 interface |
| **Unison Mode** | Detune multiple voices for thick supersaw-style unison leads |
| **MIDI Sequencer** | External MIDI input syncs the step sequencer to DAW tempo |
